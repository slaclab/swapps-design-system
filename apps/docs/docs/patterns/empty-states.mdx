# Empty states

:::info Guidelines pending
Empty state patterns are being defined. The principles below provide initial guidance.
:::

## When to show an empty state

- A data table has no rows.
- A search returns no results.
- A user has not created any items yet.

## Principles

- Explain why the area is empty.
- Suggest what the user can do next (e.g., "Create your first experiment").
- Keep the message concise and helpful.
- Use an appropriate visual treatment — centered text, optional illustration.
