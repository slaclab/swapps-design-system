# Alarms

Alarm indication helps operators detect and respond to abnormal situations. The SWAPPS alarm system follows PAS High Performance HMI principles, adapted for EPICS-based scientific control systems.

## Severity levels

export const Swatch = ({light, dark}) => (

  </span>

| Severity | PAS Priority | Color | Token | Meaning |
|---|---|---|---|---|
| `major` | 1 — Critical | <Swatch light="#da1e28" dark="#fa4d56" /> | `--swapps-alarm-major` | Immediate attention required |
| `minor` | 2 — Low | <Swatch light="#f1c21b" dark="#fddc69" /> | `--swapps-alarm-minor` | Outside normal range |
| `warning` | 3 — Medium | <Swatch light="#ff832b" dark="#ffb784" /> | `--swapps-alarm-warning` | Approaching critical threshold |
| `invalid` | 4 — Diagnostic | <Swatch light="#a56eff" dark="#be95ff" /> | `--swapps-alarm-invalid` | Sensor or data quality issue |
| `disconnected` | — | <Swatch light="#8d8d8d" dark="#a8a8a8" /> | `--swapps-alarm-disconnected` | Connection lost |
| `none` | — | — | — | No alarm |

Each token also has a `-border` variant (e.g., `--swapps-alarm-major-border`).

:::info EPICS mapping
EPICS `HIHI`/`LOLO` thresholds → `major`. `HIGH`/`LOW` → `minor`. `INVALID` severity → `invalid`.
:::

## Core principles

From PAS *High Performance HMI* (Hollifield & Perez, 2015):

:::warning Color is never the sole indicator
Every alarm must pair color with at least one other cue — shape, text, border style, or position. Many operators have color-vision deficiencies.
:::

**Reserve bright colors for abnormal states.** A well-running system should look calm. If red and yellow appear during normal operation, alarms lose their visual impact.

**Redundant coding at a glance:**

### Border

The most common method. A colored border appears when an alarm is active.

<BorderDemo />

- **Solid border** — active alarm
- **Dashed border** — suppressed or shelved alarm (still visible, clearly differentiated)

Used by: `PVSymbol`, `ByteIndicator`, `MultiStateIndicator`, `EmbeddedDisplay`

## Flashing behavior

Per PAS guidance, animation is reserved **only** for unacknowledged alarms:

| State | Visual |
|---|---|
| Unacknowledged | Indicator flashes (motion is detected in peripheral vision) |
| Acknowledged, active | Static indicator in alarm color |
| Cleared | Indicator disappears |

:::caution Not yet implemented
Unacknowledged alarm flashing is not yet implemented in SWAPPS controls. This documents the target behavior.
:::

## Dark mode

Alarm tokens automatically adapt to the active Carbon theme. Dark variants use brighter, higher-value colors to maintain the same visual urgency on dark backgrounds.

## Usage

```tsx
import { PVLabel, PVSymbol } from '@swapps/controls';
import type { AlarmSeverity } from '@swapps/controls';

// Border indication
<PVSymbol symbol={pumpSymbol} alarmSeverity="major" />

// Text color indication
<PVLabel value={480.1} units="psi" alarmSeverity="minor" />
```

JavaScript constants for SVG or non-CSS contexts:

```ts
import {
  ALARM_COLORS,       // light theme hex values
  ALARM_COLORS_DARK,  // dark theme hex values
  ALARM_BORDER_COLORS,
  ALARM_BORDER_COLORS_DARK,
} from '@swapps/controls';
```
