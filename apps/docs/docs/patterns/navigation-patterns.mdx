# Navigation patterns

## Top navigation

Use the [AppHeader](/docs/components/app-header) for primary navigation when the application has a small number of top-level sections (roughly 2–7 items).

## Side navigation

Use Carbon's `SideNav` for applications with many sections or deep hierarchies. Side navigation is persistent and gives users a clear overview of available sections.

## Combined

Applications can combine top navigation (for primary sections) with side navigation (for subsections within each section).

## Guidance

- Keep top-level navigation items to 7 or fewer.
- Use clear, concise labels.
- Indicate the active section visually.
- Ensure navigation is keyboard-accessible.
- On mobile, collapse navigation behind a menu button.
