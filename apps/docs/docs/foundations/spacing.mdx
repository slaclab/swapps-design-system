# Spacing and sizing

## Approach

Consistent spacing creates visual rhythm and improves scannability. The SWAPPS Design System uses Carbon's [spacing scale](https://carbondesignsystem.com/elements/spacing/overview/).

## Spacing scale

Carbon uses a base-16 spacing scale:

| Token | Value |
|---|---|
| `$spacing-01` | 2px |
| `$spacing-02` | 4px |
| `$spacing-03` | 8px |
| `$spacing-04` | 12px |
| `$spacing-05` | 16px |
| `$spacing-06` | 24px |
| `$spacing-07` | 32px |
| `$spacing-08` | 40px |
| `$spacing-09` | 48px |

## Layout spacing

For larger layout gaps, Carbon provides layout tokens:

| Token | Value |
|---|---|
| `$spacing-10` | 64px |
| `$spacing-11` | 80px |
| `$spacing-12` | 96px |
| `$spacing-13` | 160px |

## Guidance

- Use Carbon spacing tokens rather than arbitrary pixel values.
- Maintain consistent padding within component groups.
- Use larger spacing to separate distinct content sections.
- Align elements to Carbon's grid where appropriate.
