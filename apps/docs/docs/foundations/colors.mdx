# Colors

## Approach

The SWAPPS Design System uses IBM Carbon's color system as its foundation. Carbon provides a comprehensive set of color tokens for backgrounds, text, interactive elements, status indicators, and more.

SWAPPS extends Carbon with three additional token sets for concerns specific to multi-laboratory scientific applications.

## Carbon color tokens

Use Carbon's [color tokens](https://carbondesignsystem.com/elements/color/tokens/) for standard UI elements. These tokens adapt automatically to light and dark themes.

Common token categories:

| Category | Examples | Purpose |
|---|---|---|
| **Background** | `$background`, `$layer-01` | Page and container backgrounds |
| **Text** | `$text-primary`, `$text-secondary` | Text content |
| **Interactive** | `$interactive`, `$link-primary` | Buttons, links, active elements |
| **Support** | `$support-error`, `$support-success` | Status and feedback |
| **Border** | `$border-subtle`, `$border-strong` | Dividers and outlines |

## SWAPPS token extensions

### Brand tokens

Organization-specific accent colors, configured through `SWAPPSThemeProvider`:

| Token | Purpose | Used by |
|---|---|---|
| `--swapps-brand-primary` | Organization's primary color | General UI only |
| `--swapps-brand-accent` | Organization's accent color | General UI only |

These are `transparent` by default and only take effect when a laboratory configures them. They are **not used** by scientific controls or chart components.

### Semantic status tokens

Fixed, system-defined colors for functional states:

| Token | Purpose |
|---|---|
| `--swapps-status-normal` | Normal/healthy state |
| `--swapps-status-warning` | Warning condition |
| `--swapps-status-error` | Error state |
| `--swapps-status-critical` | Critical alarm |
| `--swapps-status-disabled` | Disabled/inactive |
| `--swapps-status-disconnected` | Disconnected from data source |
| `--swapps-status-unknown` | Unknown/indeterminate state |

These remain consistent regardless of the selected laboratory. See [Themes overview](/docs/themes/overview) for a visual reference.

## Guidance

- **Do** use Carbon color tokens for all standard UI elements.
- **Do** use `--swapps-status-*` tokens for functional control states.
- **Do** use `--swapps-viz-series-*` tokens for chart data series.
- **Do** ensure sufficient color contrast (WCAG AA minimum).
- **Do not** hardcode hex values in component code — use tokens.
- **Do not** use brand tokens in scientific controls or charts.
- **Do not** assume SLAC-specific colors are part of the shared system.
