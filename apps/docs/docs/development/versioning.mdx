# Versioning and releases

## Current status

The `@swapps/ui` package is in early development (v0.1.0) and is not yet published to a package registry.

## Versioning strategy

The package will follow [Semantic Versioning](https://semver.org/):

- **Major** (1.0.0) — Breaking changes to the public API.
- **Minor** (0.x.0) — New features, backward-compatible.
- **Patch** (0.0.x) — Bug fixes, backward-compatible.

While in `0.x`, the API may change between minor versions.

## Publishing

:::info Package registry — pending decision
The npm scope (`@swapps`) and target registry have not been finalized. Options include:

- The public npm registry
- A GitHub Packages registry
- An internal package registry

This decision will be documented when resolved.
:::

## Changelog

Changes will be tracked in the [changelog](/docs/resources/changelog).

## Breaking changes

Breaking changes should be:

1. Discussed in a GitHub issue before implementation.
2. Documented in the changelog.
3. Accompanied by a migration guide when the impact is significant.
