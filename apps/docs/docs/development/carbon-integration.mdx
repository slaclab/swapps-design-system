# Carbon integration

The SWAPPS Design System is built on [IBM Carbon](https://carbondesignsystem.com/). All SWAPPS components use Carbon under the hood, and applications should use Carbon components directly for standard UI primitives.

## What Carbon provides

- **UI primitives** — Buttons, inputs, dropdowns, tables, modals, notifications, and more.
- **Design tokens** — Colors, typography, spacing, and layout values.
- **Accessibility** — ARIA patterns, keyboard navigation, focus management.
- **Theming** — Light and dark mode support through theme tokens.
- **Grid system** — Responsive layout grid.

## What SWAPPS adds

SWAPPS components focus on **application-level patterns** that Carbon does not provide as single components:

- Configurable application headers with organization branding
- Navigation patterns for scientific applications
- Application shell layouts
- Theme configuration for multi-organization use
- Scientific controls and visualization (planned)

## Using Carbon components directly

Import Carbon components alongside SWAPPS components — there is no conflict:

```tsx
import { AppHeader } from '@swapps/ui';
import { Button, TextInput, DataTable, Modal } from '@carbon/react';
```

## Carbon styles

Carbon requires its stylesheet to be loaded. Include it in your application entry point:

```tsx
import '@carbon/react/es/styles.css';
```

Or with Sass for more control:

```scss
@use '@carbon/react';
```

## Common Carbon components

### Buttons

```tsx
import { Button } from '@carbon/react';

<Button>Primary action</Button>
<Button kind="secondary">Secondary action</Button>
<Button kind="danger">Destructive action</Button>
<Button kind="ghost">Ghost action</Button>
```

- Use **primary** for the main action on a page or section.
- Use **danger** for destructive actions (delete, remove).
- Limit primary buttons to one per section.
- Use clear, action-oriented labels ("Save changes", not "OK").
- For icon-only buttons, provide an `aria-label`.

[Carbon Button docs](https://react.carbondesignsystem.com/?path=/story/components-button--default)

### Forms and inputs

| Component | Import |
|---|---|
| Text input | `TextInput` |
| Text area | `TextArea` |
| Select / Dropdown | `Dropdown`, `Select` |
| Checkbox | `Checkbox` |
| Radio button | `RadioButton`, `RadioButtonGroup` |
| Toggle | `Toggle` |
| Number input | `NumberInput` |
| Date picker | `DatePicker`, `DatePickerInput` |

```tsx
import { TextInput, Dropdown, Button } from '@carbon/react';

function ExperimentForm() {
  return (
    <form>
      <TextInput id="experiment-name" labelText="Experiment name" />
      <Dropdown
        id="beam-line"
        titleText="Beam line"
        items={['BL 1-5', 'BL 2-1', 'BL 11-2']}
        label="Select beam line"
      />
      <Button type="submit">Create experiment</Button>
    </form>
  );
}
```

- Always provide visible labels using `labelText`.
- Use `helperText` for additional context.
- Use `invalidText` and `invalid` props for validation messages.

[Carbon form docs](https://react.carbondesignsystem.com/?path=/story/components-textinput--default) · [Form pattern guidelines](https://carbondesignsystem.com/patterns/forms-pattern/)

### Data tables

```tsx
import {
  DataTable, Table, TableHead, TableRow,
  TableHeader, TableBody, TableCell,
} from '@carbon/react';

const headers = [
  { key: 'name', header: 'Name' },
  { key: 'status', header: 'Status' },
];

const rows = [
  { id: '1', name: 'Run 4523', status: 'Complete' },
  { id: '2', name: 'Run 4524', status: 'Running' },
];

<DataTable rows={rows} headers={headers}>
  {({ rows, headers, getTableProps, getHeaderProps, getRowProps }) => (
    <Table {...getTableProps()}>
      <TableHead>
        <TableRow>
          {headers.map((h) => (
            <TableHeader {...getHeaderProps({ header: h })} key={h.key}>
              {h.header}
            </TableHeader>
          ))}
        </TableRow>
      </TableHead>
      <TableBody>
        {rows.map((row) => (
          <TableRow {...getRowProps({ row })} key={row.id}>
            {row.cells.map((cell) => (
              <TableCell key={cell.id}>{cell.value}</TableCell>
            ))}
          </TableRow>
        ))}
      </TableBody>
    </Table>
  )}
</DataTable>
```

[Carbon DataTable docs](https://react.carbondesignsystem.com/?path=/story/components-datatable--default)

### Dialogs

```tsx
import { Modal } from '@carbon/react';

<Modal
  open={isOpen}
  onRequestClose={() => setIsOpen(false)}
  modalHeading="Confirm deletion"
  primaryButtonText="Delete"
  secondaryButtonText="Cancel"
  danger
>
  <p>Are you sure you want to delete this experiment?</p>
</Modal>
```

- Use modals sparingly — they interrupt the user's workflow.
- Always include a way to dismiss (close button, cancel action).
- Use `danger` prop for destructive confirmations.

[Carbon Modal docs](https://react.carbondesignsystem.com/?path=/story/components-modal--default)

### Notifications

```tsx
import { InlineNotification, ToastNotification } from '@carbon/react';

<InlineNotification kind="success" title="Saved" subtitle="Changes saved." />
<ToastNotification kind="error" title="Connection lost" timeout={5000} />
```

| Kind | Use |
|---|---|
| `info` | General information |
| `success` | Completed action |
| `warning` | Potential issue |
| `error` | Failure or problem |

[Carbon Notification docs](https://react.carbondesignsystem.com/?path=/story/components-notifications-inline--default)

## Carbon version

`@swapps/ui` declares `@carbon/react` as a dependency. The version is managed by the package and should not need to be installed separately.
