## Designed for cross-laboratory adoption

Maintained by the **S**oft**w**are **App**lications team (SWAPPS) at SLAC National Accelerator Laboratory, the design system is built so that **any development team** — at SLAC or other laboratories — can adopt the shared components and configure them with their own organization's identity.

IBM Carbon provides foundational UI primitives (buttons, forms, tables, dialogs). SWAPPS adds **application-level patterns** that standardize how scientific and technical software looks and behaves. For standard UI elements, use Carbon directly — see the [Carbon integration guide](/docs/development/carbon-integration).
