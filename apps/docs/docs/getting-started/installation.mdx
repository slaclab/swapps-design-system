# Installation

## Prerequisites

- **Node.js** 20 or later
- **React** 18 or 19
- A package manager: npm, yarn, or pnpm

## Install the package

:::note Package registry pending
The `@swapps/ui` package is not yet published to a package registry. During development, it is consumed via the pnpm workspace. The instructions below describe the intended installation experience once the package is published.
:::

```bash
# npm
npm install @swapps/ui

# pnpm
pnpm add @swapps/ui

# yarn
yarn add @swapps/ui
```

## Peer dependencies

`@swapps/ui` requires React as a peer dependency. If your project already uses React, no additional installation is needed.

```json
{
  "peerDependencies": {
    "react": "^18.0.0 || ^19.0.0",
    "react-dom": "^18.0.0 || ^19.0.0"
  }
}
```

## Carbon styles

Components in `@swapps/ui` are built on IBM Carbon and require Carbon's stylesheet to be loaded in your application.

Add the following import to your application's entry point or root layout:

```tsx
import '@carbon/react/es/styles.css';
```

Alternatively, if your project uses Sass:

```scss
@use '@carbon/react';
```

See the [Carbon documentation](https://carbondesignsystem.com/developing/frameworks/react/) for more details on styling setup.

## TypeScript

`@swapps/ui` ships with TypeScript declarations. No separate `@types` package is needed.
