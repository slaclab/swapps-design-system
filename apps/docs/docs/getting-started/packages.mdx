## What about buttons, forms, and tables?

For standard UI primitives, use [IBM Carbon](https://carbondesignsystem.com/) directly alongside SWAPPS packages. Carbon provides buttons, text inputs, data tables, dialogs, notifications, and [much more](https://carbondesignsystem.com/components/overview/) — all accessible and well-documented.

```tsx
import { Button, TextInput } from '@carbon/react';
import { AppHeader } from '@swapps/ui';
```

See the [Carbon Components](/docs/components/carbon-primitives) for details on using Carbon components in your application.
