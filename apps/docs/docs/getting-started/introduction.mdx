# SWAPPS Design System

The SWAPPS Design System provides a shared foundation for building consistent, accessible, and maintainable software interfaces.

## What is this?

This design system combines:

- **Design guidelines** — Colors, typography, spacing, layout patterns, and accessibility standards.
- **A React component library** — Reusable, configurable application-level components built on [IBM Carbon](https://carbondesignsystem.com/).
- **This documentation website** — A central reference for developers using the system.

## Who is it for?

The primary audience is the **SWAPPS team** at SLAC National Accelerator Laboratory, but the system is designed for broader adoption.

Any software development team can:

1. Browse the documentation and guidelines.
2. Install the `@swapps/ui` component library.
3. Configure organization-specific branding (logo, name, colors).
4. Build applications using shared components and patterns.

## What does it provide?

| Area | Description |
|---|---|
| **Foundations** | Design principles, colors, typography, spacing, accessibility |
| **Components** | Application header, navigation, layout shells, and more |
| **Patterns** | Application layouts, loading states, error handling, responsive design |
| **Themes** | Configurable organization branding with light and dark mode support |

## Built on IBM Carbon

SWAPPS components are built on top of [IBM Carbon](https://carbondesignsystem.com/), an open-source design system with robust accessibility support, comprehensive documentation, and a mature React component library.

Carbon provides the foundational UI primitives — buttons, inputs, tables, dialogs, and more. SWAPPS adds reusable **application-level patterns** that standardize how scientific and technical software looks and behaves.
