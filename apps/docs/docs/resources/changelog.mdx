# Changelog

## 0.1.0 — Initial foundation

### Added

- **Monorepo** — pnpm workspace with `apps/docs` and `packages/ui`.
- **Documentation website** — Docusaurus 3 with custom homepage, navigation, and content structure.
- **`AppHeader` component** — Configurable application header built on Carbon's UI Shell. Supports `orgName`, `appTitle`, `navItems`, `logo`, and accessible labeling.
- **Interactive playground** — Live AppHeader preview in the documentation with configurable props.
- **Component tests** — Vitest + React Testing Library tests for AppHeader.
- **CI pipeline** — GitHub Actions workflow for typecheck, test, and build validation.
- **Documentation sections** — Getting Started, Foundations, Components, Patterns, Themes, Development, and Resources.
