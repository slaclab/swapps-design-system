# Palettes

14-color categorical palettes for light and dark themes, derived from Carbon's data visualization color guidelines.

## CATEGORICAL_PALETTE

Two 14-color arrays — one for light backgrounds, one for dark — optimized for distinguishability and accessibility.

```tsx
import { CATEGORICAL_PALETTE, baseChartOption, useChartTheme } from '@swapps/charts';

function MultiSeriesChart() {
  const theme = useChartTheme();
  const mode = theme === CHART_THEMES.dark ? 'dark' : 'light';

  const option = {
    ...baseChartOption(theme, { colors: CATEGORICAL_PALETTE[mode] }),
    series: traces.map((t) => ({ type: 'line', name: t.name, data: t.data })),
  };

  return <SWAPPSChart option={option} />;
}
```

## seriesColor

Cycling color picker for the i-th series. Wraps around the 14-color palette.

```tsx
import { seriesColor } from '@swapps/charts';

const color0 = seriesColor(0, 'light');  // '#6929c4' (Purple 70)
const color1 = seriesColor(1, 'light');  // '#1192e8' (Cyan 50)
const color14 = seriesColor(14, 'light'); // wraps to '#6929c4'
```

Useful when you need to reference a series color outside of ECharts (e.g., in a custom legend or a status label).
