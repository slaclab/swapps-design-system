# Charts & Visualization

Charting utilities from `@swapps/charts` for scientific data visualization. Built on [Apache ECharts](https://echarts.apache.org/) with Carbon-themed styling, following the same architecture as SLAC's [Canopy SDK](https://github.com/slaclab/canopy-sdk-js).

## Architecture

The package provides a **single chart component** (`SWAPPSChart`) and **theming utilities** — not individual chart-type components. You build any chart type (time series, scatter, waveform, event plot) by constructing an ECharts `option` object and passing it to `SWAPPSChart`. This gives you full access to ECharts' capabilities without an abstraction layer in between.

```tsx
import { SWAPPSChart, baseChartOption, useChartTheme } from '@swapps/charts';

const theme = useChartTheme();
const option = {
  ...baseChartOption(theme),
  xAxis: { type: 'time' },
  series: [{ type: 'line', data: myData }],
};

<SWAPPSChart option={option} />
```

## Key design decisions

- **Option-based theming** — Carbon token values are resolved into a `ChartTheme` object and applied through the ECharts option, not ECharts' theme registration system. This avoids re-creating chart instances on theme change.
- **`animation: false` by default** — Live PV data updates frequently; animation causes jitter.
- **Canvas renderer** — Default renderer for performance with large datasets.
- **Consumer manages data** — The chart package does not subscribe to PVs or buffer data. Use `usePV()` from your data layer, accumulate arrays, throttle updates to ~150ms, and pass fresh option objects.
- **`echarts.connect()` support** — Link multiple charts via the `group` prop so they share tooltip crosshairs and dataZoom actions.
