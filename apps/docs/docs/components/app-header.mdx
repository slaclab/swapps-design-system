# AppHeader

A configurable application header built on Carbon's UI Shell. Provides a consistent top bar for application title, organization branding, and primary navigation.

## Interactive preview

Try different configurations below. Select an organization preset or enter custom values.

<AppHeaderPlayground />

## Installation

```bash
npm install @swapps/ui
```

Ensure Carbon styles are loaded in your application:

```tsx
import '@carbon/react/es/styles.css';
```

## Usage

```tsx
import { AppHeader } from '@swapps/ui';

function App() {
  return (
    <AppHeader
      orgName="SLAC"
      appTitle="Experiment Tracker"
      navItems={[
        { label: 'Dashboard', href: '/dashboard' },
        { label: 'Experiments', href: '/experiments' },
        { label: 'Settings', href: '/settings' },
      ]}
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `appTitle` | `string` | **(required)** | Application title displayed in the header |
| `orgName` | `string` | — | Organization or laboratory name, shown as a prefix |
| `navItems` | `NavItem[]` | `[]` | Navigation items in the header bar |
| `homeHref` | `string` | `"/"` | URL for the header title link |
| `logo` | `ReactNode` | — | Optional logo element before the header name |
| `globalActions` | `ReactNode` | — | Elements in the global action area (right side) |
| `skipToContentLabel` | `string` | `"Skip to main content"` | Accessible label for the skip link |
| `aria-label` | `string` | Auto-generated | Accessible label for the header landmark |

### NavItem

```ts
interface NavItem {
  label: string;
  href: string;
}
```

## Organization branding

The `AppHeader` does not hardcode any organization's identity. Pass your organization's name, logo, and application title through props:

```tsx
// SLAC application
<AppHeader orgName="SLAC" appTitle="Beam Status" />

// Another laboratory
<AppHeader
  orgName="Fermilab"
  appTitle="Accelerator Monitor"
  logo={<img src="/fermilab-logo.svg" alt="Fermilab" height={20} />}
/>

// No organization prefix
<AppHeader appTitle="Shared Tool" />
```

## Navigation

Pass an array of `NavItem` objects to render links in the header navigation area:

```tsx
<AppHeader
  appTitle="My App"
  navItems={[
    { label: 'Home', href: '/' },
    { label: 'Data', href: '/data' },
    { label: 'Admin', href: '/admin' },
  ]}
/>
```

When `navItems` is empty or omitted, no navigation bar is rendered.

## Global actions

Use the `globalActions` prop to render elements in the right side of the header (e.g., user menu, notifications):

```tsx
import { HeaderGlobalAction } from '@carbon/react';
import { UserAvatar } from '@carbon/icons-react';

<AppHeader
  appTitle="My App"
  globalActions={
    <HeaderGlobalAction aria-label="User profile">
      <UserAvatar size={20} />
    </HeaderGlobalAction>
  }
/>
```

## Accessibility

- Includes a **skip-to-content** link as the first focusable element.
- Uses Carbon's `Header` component, which renders a `<header>` landmark with an `aria-label`.
- Navigation renders in a `<nav>` element with an accessible label.
- All navigation items are keyboard-accessible.

## Built on Carbon

`AppHeader` wraps Carbon's [UI Shell](https://react.carbondesignsystem.com/?path=/story/components-ui-shell--header-base) components:

- `Header`
- `HeaderName`
- `HeaderNavigation`
- `HeaderMenuItem`
- `SkipToContent`

## Known limitations

- **Mobile responsiveness** — The header does not yet include a hamburger menu for mobile viewports. This is planned.
- **Active nav state** — Navigation items do not currently indicate the active page. This requires router integration.
- **Sub-menus** — Dropdown sub-navigation is not yet supported.
