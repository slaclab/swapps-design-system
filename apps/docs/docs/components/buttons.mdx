# Buttons

Buttons are provided by IBM Carbon. Use Carbon's `Button` component directly.

## Usage

```tsx
import { Button } from '@carbon/react';

<Button>Primary action</Button>
<Button kind="secondary">Secondary action</Button>
<Button kind="tertiary">Tertiary action</Button>
<Button kind="ghost">Ghost action</Button>
<Button kind="danger">Destructive action</Button>
```

## Guidelines

- Use **primary** buttons for the main action on a page or section.
- Use **secondary** for alternative actions.
- Use **danger** for destructive actions (delete, remove).
- Limit primary buttons to one per section to maintain clear hierarchy.
- Use clear, action-oriented labels ("Save changes", not "OK").

## Accessibility

- Carbon buttons include proper focus styles and keyboard support.
- Use descriptive labels — avoid generic text like "Click here".
- For icon-only buttons, provide an `aria-label` or `tooltipText`.
