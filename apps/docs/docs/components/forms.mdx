# Forms and inputs

Form elements are provided by IBM Carbon. Use Carbon's form components directly.

## Common components

| Component | Import |
|---|---|
| Text input | `TextInput` |
| Text area | `TextArea` |
| Select / Dropdown | `Dropdown`, `Select` |
| Checkbox | `Checkbox` |
| Radio button | `RadioButton`, `RadioButtonGroup` |
| Toggle | `Toggle` |
| Number input | `NumberInput` |
| Date picker | `DatePicker`, `DatePickerInput` |

## Example

```tsx
import { TextInput, Dropdown, Button } from '@carbon/react';

function ExperimentForm() {
  return (
    <form>
      <TextInput
        id="experiment-name"
        labelText="Experiment name"
        placeholder="Enter a name"
      />
      <Dropdown
        id="beam-line"
        titleText="Beam line"
        items={['BL 1-5', 'BL 2-1', 'BL 11-2']}
        label="Select beam line"
      />
      <Button type="submit">Create experiment</Button>
    </form>
  );
}
```

## Guidance

- Always provide visible labels using `labelText`.
- Use `helperText` for additional context.
- Use `invalidText` and `invalid` props for validation messages.
- Group related fields logically.
- Follow Carbon's [form pattern guidelines](https://carbondesignsystem.com/patterns/forms-pattern/).
