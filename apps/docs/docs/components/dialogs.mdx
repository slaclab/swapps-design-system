# Dialogs

Dialogs (modals) are provided by IBM Carbon. Use Carbon's `Modal` or `ComposedModal` components.

## Usage

```tsx
import { Modal } from '@carbon/react';

<Modal
  open={isOpen}
  onRequestClose={() => setIsOpen(false)}
  modalHeading="Confirm deletion"
  primaryButtonText="Delete"
  secondaryButtonText="Cancel"
  danger
>
  <p>Are you sure you want to delete this experiment? This action cannot be undone.</p>
</Modal>
```

## Guidance

- Use modals sparingly — they interrupt the user's workflow.
- Provide clear headings that describe the action or decision.
- Always include a way to dismiss the modal (close button, cancel action).
- Use `danger` prop for destructive confirmations.
