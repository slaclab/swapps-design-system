# Scientific Controls

Domain-specific widgets from `@swapps/controls` for displaying and interacting with process variable data. These components provide alarm-severity awareness, PV-specific formatting, and specialized rendering that general-purpose Carbon components cannot.

Inspired by [PyDM](https://slaclab.github.io/pydm/) display and container widgets, rebuilt for the web with React, Carbon theming, and the SWAPPS alarm system.

## Shared concepts

All scientific control components share a common alarm severity model:

```ts
type AlarmSeverity = 'none' | 'minor' | 'major' | 'invalid' | 'disconnected';
```

Components accept `alarmSeverity` and `connected` props through the shared `BaseWidgetProps` interface. Alarm state drives border color, text color, and indicator fills automatically.
